# M00 Для дорослого

## Коротко {#meta}

- модуль: `M00 Підготовка матеріалів`
- серіал: `Чудесна мандрівка Нільса з дикими гусьми`, `1991`
- книга: `Сельма Лагерлеф, Дивовижні мандри Нільса з дикими гусьми`
- головний фокус: `як зберігати і готувати матеріали`

## Головна ідея {#idea}

`M00` потрібен для того, щоб до старту курсу зібрати зрозумілу систему зберігання.

Що можна сказати дитині на старті:

`Ми починаємо подорож разом із хлопчиком Нільсом. На нас чекають місії, герої, локації, підказки і пам'ятні знаки. Усе, що ти проходитимеш, залишатиметься в магічній скрині, а на мапі ти побачиш, як далеко вже дістався.`

Перша місія:

- зробити нашу `магічну скриню`;
- підписати папку або коробку;
- розфарбувати або прикрасити її;
- зібрати конверти або файли для матеріалів.

Для дорослого `магічна скриня` - це велика папка або коробка для всього курсу.

Далі система така:

- є одна велика папка або коробка для всього курсу;
- частина матеріалів живе там постійно і повертається в кожному модулі;
- частина матеріалів додається поступово від модуля до модуля;
- разові аркуші можна або лишати в загальній папці, або складати окремо як `1 файл = 1 модуль`.

## Що підготувати {#prepare}

Підготуйте:

- `M00_map_and_tokens.pdf` - карта прогресу і жетони для всього курсу.
- `M00_parent_page.pdf` - ця інструкція для дорослого.

Ще знадобиться:

- велика папка або коробка для всіх матеріалів курсу;
- кілька файлів або конвертів усередині;
- за бажанням - набір декоративного пір'я.

## Як зібрати велику папку {#prepare-system}

У великій папці або коробці варто мати такі окремі частини:

- файл `мапа та жетони` - потрібен у кожному модулі;
- файл або конверт `картки персонажів` - поповнюється в кожному модулі;
- файл або конверт `картки локацій` - поповнюється в кожному модулі;
- файл `досьє` - аркуші заповнюються послідовно, до них треба повертатися;
- опціонально файл `тексти для читання` - якщо хочете зберігати всі тексти і повертатися до них;
- опціонально файл `картки пригод` - якщо хочете зберігати їх окремо і використовувати повторно.

Інші разові матеріали можна:

- або зберігати в загальній папці;
- або розкладати окремо за правилом `1 файл = 1 модуль`.

## Для чого кожен файл {#texts}

- `мапа та жетони` - потрібні в кожному модулі;
- `картки персонажів` - використовуються для послідовності, переказу й інших вправ;
- `картки локацій` - теж використовуються для послідовності, переказу й інших вправ;
- `досьє` - це накопичувальний блок, до якого ми будемо повертатися;
- `тексти для читання` і `картки пригод` можна вести як архів, якщо дитині подобається повертатися до вже знайомих матеріалів.

## Додаткова ідея з пір'ям {#module-flow}

### Пір'я

- до файла `мапа та жетони` можна додати невеликий набір пір'я;
- декоративне пір'я можна купити в магазинах матеріалів для біжутерії або творчості;
- протягом модулів можна збирати `пір'я зграї` як окремі знаки проходження.

### Що зробити наприкінці

- наприкінці курсу з цього пір'я можна зробити маленький веєр;
- або капелюх;
- або ловця снів.

## Як друкувати {#questions}

Краще:

- друкувати матеріали по одному модулю перед його початком;
- одразу класти нові матеріали у потрібний файл або конверт;
- після заняття повертати накопичувальні артефакти назад у велику папку.

Не варто:

- друкувати всі модулі наперед;
- змішувати картки з різних модулів без системи;
- лишати накопичувальні матеріали окремо від загальної папки.

## Як не плутатися {#support}

- кожному файлу або конверту дайте коротку назву;
- якщо зручно, підпишіть їх великими літерами;
- після кожного заняття кладіть матеріали назад одразу;
- якщо матеріал одноразовий, вирішіть наперед: зберігаємо чи ні.

Приклади назв:

- `мапа і жетони`;
- `герої`;
- `локації`;
- `досьє`;
- `читання`;
- `пригоди`.

## Що вважати успіхом {#success}

Успіх у `M00` - це якщо:

- є одна зрозуміла велика папка або коробка для всього курсу;
- карта і жетони лежать окремо і їх легко дістати в кожному модулі;
- є окреме місце для карток, локацій і досьє;
- дорослому зрозуміло, куди повертати матеріали після заняття.

## Чим завершити {#finish}

Наприкінці підготовки має бути готовий стартовий набір:

- велика папка або коробка;
- `M00_map_and_tokens.pdf`;
- підписані файли або конверти всередині;
- за бажанням - запас пір'я для майбутнього фінального виробу.

# Source Sync

## Канонічні джерела

Для синхронізації модулів, сюжету і текстів використовуємо три основні джерела:

- **основний текст (укр., скорочена редакція, 17 розділів):** `./laherlef-selma-dyvovyzhna-podorozh-nilsa-kholhersona-z-dykymy-husakamy-shvetsiieiu-(dyvovyzhni-mandry-nilsa-z-dykymy-husmy)8371.html`
- **резервний текст (рос., повний переклад Л. Брауде, 1982, ~55 розділів):** `https://www.rulit.me/author/braude-lyudmila-yulevna/udivitelnoe-puteshestvie-nilsa-holgersona-s-dikimi-gusyami-po-shvecii-pervyj-polnyj-perevod-na-russk-download-879932.html`
- **synopsis епізодів:** `https://www.imdb.com/title/tt0296386/episodes/`

## Як використовувати

- основний (укр.) текст використовуємо як перше джерело для добору уривків на читання і звірки формулювань — пріоритет за ним завжди;
- резервний (рос. Брауде) текст беремо тоді, коли потрібна інформація відсутня в укр. скороченій редакції (зокрема: розділи про шведські провінції, легенди, Дунфін/Пухопірку, ширші описи природи тощо);
- при цитуванні з російського джерела наводимо оригінал (рос.) і автоматичний переклад українською поряд, із чіткою позначкою джерела;
- synopsis епізодів використовуємо для звірки меж модулів, порядку подій і короткого змісту серій;
- якщо між джерелами є зміщення акцентів, модульна логіка спирається на реальний сюжет серій і узгоджений навчальний фокус модуля;
- у module specs, matrix і print-pack docs достатньо посилатися на `08_source_sync.md`, а не дублювати самі URL щоразу.
